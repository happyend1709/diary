# 周日记（离线日记 App）

一个完全离线、纯本地的日记记录应用（PWA）。所有数据保存在设备浏览器本地（IndexedDB），**不上传任何服务器**，断网也能使用。

## 功能
- **月历首页**：打开直接展示整月（28~31 天）日历，周一～周日排列；当天蓝色高亮；有日记的日期显示小圆点。左右滑动或点箭头切换月份。
- **点击日期写日记**：多行文字编辑、手动修改日期、保存（保存后不弹窗，直接返回）、删除。
- **标签系统**：每篇日记可绑定多个标签；编辑页可即时新建标签；标签管理页可新增/重命名/删除标签（删除标签不影响日记）。
- **列表筛选**：日记列表页先选**年份**，再选**月份**（默认最新日记所在年月），可叠加**标签**筛选出符合条件的日记。
- **备份功能**：一键导出全部日记+标签为 JSON 文件；一键导入合并（按 id 覆盖/新增，不清空本地数据）。
- **离线可用**：Service Worker 缓存全部资源，首次打开后断网也能用，可添加到手机主屏幕。

## 目录结构
```
pwa-diary/
├─ index.html        # 月历首页
├─ edit.html         # 日记编辑页
├─ tags.html         # 标签管理页
├─ list.html         # 日记列表（年/月/标签筛选）
├─ manifest.json     # PWA 配置
├─ sw.js             # Service Worker（离线缓存）
├─ icons/            # 应用图标
│  ├─ icon-192.png
│  └─ icon-512.png
├─ css/style.css     # 自带样式（无外网依赖）
└─ js/
   ├─ db.js          # IndexedDB 封装（日记+标签 CRUD、导入导出）
   ├─ common.js      # 工具函数（uuid、日期格式化、转义）
   ├─ backup.js      # 备份导入导出逻辑
   ├─ calendar.js    # 首页日历逻辑
   ├─ edit.js        # 编辑页逻辑
   ├─ tags.js        # 标签管理逻辑
   └─ list.js        # 列表筛选逻辑
```

## 本地预览（先测试）
因为用到 Service Worker / ES Module，**不能直接双击打开 HTML**，必须通过本地 HTTP 服务访问。

最简单的方式：
1. 用 VS Code 安装 **Live Server** 插件。
2. 右键 `pwa-diary` 文件夹 → Open with Live Server。
3. 浏览器打开 http://127.0.0.1:5500 即可测试。

## 数据安全提醒
- 数据只存设备本地。**卸载应用 / 清除浏览器数据会丢失全部日记**。
- 强烈建议定期点首页【导出备份】保存 JSON 文件，换机或重置时用【导入备份】恢复。
